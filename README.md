## Instalation

1. **Clone The Repositories:**
   ```bash
   git clone https://github.com/LinuxDil/Billion-Bot.git
   cd Billion-Bot
   ```
2. **Make Environment:**
   ```bash
   python3 -m venv myenv
   source myenv/bin/activate
   ```
  
3. **Install Requirements:**
   ```bash
   pip install -r requirements.txt
   ```
